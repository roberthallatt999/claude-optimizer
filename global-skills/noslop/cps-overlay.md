# CPS overrides

These come from Robert's own rules and win wherever the upstream rules below disagree.

1. **Who it's from.** Robert Hallatt, Canadian Paediatric Society. The header line reads
   "From Robert Hallatt to …". Write in the first person singular. Never "we", "our team" or
   "the team" for the CPS side: Robert is the sole developer.
2. **What it's for.** Standalone pages for a reader. CPS website templates, themes and site
   code follow the project's own brand and stack rules, not this skill.
3. **Accessibility (WCAG AA).** Two upstream style-kit colours fail 4.5:1 for text, so
   override them:
   - `--text-3: rgba(0,0,0,.55)` in light mode and `rgba(255,255,255,.5)` in dark mode.
   - `--clay-strong: #b5502f`, so white text on the main button passes.
   - Clay (`#d97757`) is for bars, borders and accents only, never text on white.
   - Every coloured status carries a word as well ("Late", "On track"), never colour alone.
   - Tabs, steps, Back/Next and opening rows work from the keyboard with a visible focus ring.
4. **Hosting contract still applies.** When the Artifact tool publishes the page, its page
   contract (allowed CDNs, dark-mode token guards, size limit) still holds. Take every design
   decision from this skill.
5. **The web version (section 8) goes to Cloudflare, not GitHub and Vercel.** Use it when
   Robert asks for a website, the web version, or a mock-up he can open or share by link. The
   stack and the rules for motion and checking in section 8 stay; its "Private by default"
   steps are replaced by these. The helper is `~/.claude/skills/noslop/scripts/cloudflare.sh`.
   1. Run `cloudflare.sh config`. If the token is missing, ask Robert to run
      `! ~/.claude/skills/noslop/scripts/cloudflare.sh setup`, then run `cloudflare.sh check`.
      Never read the token any other way, and never print it.
   2. In a new folder for the page, run `cloudflare.sh new . "<topic>" [days]`. It names the
      page `<topic>-<random hash>`, checks with Cloudflare that the name is unused, sets it to
      expire in 30 days unless Robert asks for another span, and prints the address
      `https://share.cps.ca/<name>/`. Keep the topic short and free of personal names.
      To update a page, work in its folder: `new` keeps the existing name and address. Set
      `PAGE_TITLE` in `wrangler.jsonc` to the header line's "what this is".
   3. Build into `dist/` with relative asset links (Vite: `base: './'`), because the page is
      served under its path. A single HTML page goes in `dist/index.html`.
   4. Deploy with `cloudflare.sh wrangler deploy`. The safety hook asks Robert first.
   5. Make a passcode of three plain words and two digits. Set it with
      `printf '%s' '<passcode>' | cloudflare.sh wrangler secret put PASSCODE --name <name>`.
      Until it is set, the page answers "not ready" to everyone.
   6. Check from outside with curl: the address from `cloudflare.sh url <name>` must answer
      401, and a POST of the passcode to `<address>__unlock` must answer 303. A 403 page that
      says "Sorry, you have been blocked" is a Cloudflare security rule on the zone, not the
      gate: tell Robert and leave the rule alone.
   7. End with 3 lines: the link, the passcode, and the expiry date. After that date the page
      answers "expired" by itself.

   Managing pages: `cloudflare.sh list` shows every page on share.cps.ca with its dates.
   `cloudflare.sh prune` lists the expired ones, and `prune --delete` removes them.
   `cloudflare.sh delete <name>` removes one page early. Both deletes need Robert's yes, and
   neither touches a Worker that isn't served from share.cps.ca.

   Don't create a GitHub repo or push unless Robert asks. Cloudflare serves from outside
   Canada and the passcode is light protection for mock-ups, so never put personal information
   about members, patients, families or staff on these pages. When Robert hasn't asked for a
   website or a link, a private artifact is the default.
6. **Polish tools are opt-in, per page.** Emil Kowalski's skills, Impeccable and Magic UI
   are not installed by default. Offer them once when building the web version. Install them
   only in that page's folder and only on Robert's yes, never globally.
7. **Language.** Write in the language of the source material. English prose uses Canadian
   spelling (colour, centre, paediatric).
