# Rules for every stack. Each must match only secret-shaped files, never a file an app
# needs: on macOS git matches case-insensitively, so a loose glob like *apikey* also hides
# ApiKey.php. Secrets in ordinary files are caught at commit time by the content scan
# (safety-guard.sh --pre-commit), not by file name here.
